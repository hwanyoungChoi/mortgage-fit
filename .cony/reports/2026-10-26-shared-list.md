# 함께 쓰는 목록(같이 편집)

## 결과

초대 링크로 두 계정이 한 저장 목록을 함께 쓰고, 한쪽이 고치면 다른 쪽에도 보인다(앱으로 돌아올 때와 함께 쓰는 동안 30초마다). 기존 값 복사 공유 링크는 그대로.

## 태스크별 결과

1. 서버(가구·초대·수락·나가기, 가구 범위 목록·예산·순서) — 완료
2. 화면(`#/invite/{token}`, [함께 쓰기] 시트, 함께 쓰는 중 표시·나가기, 30초 재조회) — 완료
3. 배포·검증 — 원격 마이그레이션 0005 완료, PR 머지 후 운영 확인 필요

## 결정

- [ADR-028](../decisions/028-shared-list.md): households + users.household_id(합집합), 가구일 때만 30초 폴링, 로그인 후 초대 복귀는 서버 쿠키. **검토 권장**: 구성원이 상대 매물을 지우면 되돌릴 수 없음
- 되돌림: ADR-023의 "공유받은 사람은 값만 복사" — 새 초대 방식에 한해 같이 편집

## 수용 기준

- AC-0: 원격 마이그레이션 직전·직후 diff 빔, 혼자 쓰는 사용자 56요청 main과 동일(me의 household:null만 추가), 비로그인 localStorage 원문 불변, 기존 공유 링크 사본 추가 그대로, 혼자 쓰는 사용자 주기 요청 0건
- AC-1~7: 로컬(be curl, fe 360px)로 통과. 동시 수락 5회 한쪽만 성공. 실제 카카오 로그인 성공 콜백 → 초대 화면 복귀는 운영에서 확인 필요
- 롤백: 가구가 하나도 없을 때만 이전 Worker로 안전
