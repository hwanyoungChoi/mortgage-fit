# 예산 외 항목: 구매 완료 줄을 예산에 반영/미반영 고르기

## 결과

인테리어 줄마다 "예산에 반영" 체크를 끌 수 있다. 끈 줄은 남은 예산·지출·막대·묶음 합계에서 빠지고, 요약에 "예산 외 n원"으로 따로 보인다.

요청 원문(함께 쓰는 사람): "구매 완료한거 예산에 반영/미반영 선택하게 못하낭, 걍 예산 외에서 구매한 것들도 있는딩"

## 태스크별 결과

1. **저장·계산·시트·목록·요약** — 항목 `isOffBudget?: true`(없으면 반영). 서버 코드 diff 0(클라이언트 검증 함수 공유). 줄 시트 [확정] 아래 "예산에 반영" 체크, 목록 금액 아래 흐린 "예산 외", 요약 "예산 외 n원".
2. **표·인쇄·CSV·홈 카드** — 줄 비고 "예산 외", 계 비고 "금액 미정 n건 제외 · 예산 외 n원 제외", 표 머리에 예산 외 금액. 홈 카드는 요약 값을 그대로 씀. 시트의 두 체크 간격을 줄임(터치 영역 48px 유지).
3. **검증** — 로그아웃·로그인·함께 쓰기 세 경우와 /import 왕복, 360px 화면.

## 팀이 내린 결정

- [ADR-038](../decisions/038-off-budget-item.md) 항목 필드 `isOffBudget?: true`, 1단계 배포. fe·be·qa 조건부 찬성. **검토 권장**(저장 형식): 견적마다 일부만 예산 외인 경우가 생기면 견적 단위로 다시 본다.

## 수용 기준 결과

- AC-1~AC-8 통과. [위험] AC는 qa가 버그를 일부러 되살려 테스트가 잡는지 확인(태스크 1: 4건, 태스크 2: 3건, 태스크 3: 1건).
- 흐름 규칙 건너뜀: 없음.
- 지표(2026-11-06 10:28부터): 에이전트 실행 7, 되돌림 0, hook 차단 0. 토큰 리드 3.0M / 전체 25.9M(약 12%). 시간: 구현 13분, 테스트 21분, 조율 2분. 테스트 비중 62%.

## 화면 확인

- qa가 360px로 확인: 목록 "예산 외", 시트 체크, 요약, 표(E·F·G), 인쇄 A4 PDF, CSV, 홈 카드, 함께 쓰는 중 서버 출처.
- 사람 확인 필요: 실기기 터치(두 체크 구분), 스크린리더, 엑셀·넘버스에서 CSV 계 비고, 실제 두 기기 함께 쓰기.

## 사용자 확인 필요 (제안 기본값으로 진행함)

스펙 [interior-budget-exclude.md](../specs/interior-budget-exclude.md)의 U1~U9. 핵심만:

- U1 새 줄 기본값은 '반영'
- U2·U9 확정 안 한 줄에도 체크가 보이고 "예산 외" 글자도 붙음
- U3 토글 위치는 줄 시트 [확정] 아래(목록 줄에는 없음)
- U5 예산 외는 남은 예산·지출·막대에서 빠지고 요약에 "예산 외 n원"
- U7 표·CSV 줄 금액은 그대로 두고 비고 "예산 외". 엑셀에서 열을 직접 더하면 계보다 크게 나옴
- U8 요약 "지출 완료" 행은 완료 금액이 0보다 클 때만(홈과 같게)
