# 계정·함께 쓰기를 홈으로, 가리기는 저장 목록에만 — 최종 보고

## 결과

로그인·로그아웃, 함께 쓰기·나가기, "함께 쓰는 중" 표시가 홈 계정 자리로 옮겨졌습니다. 카카오 로그인 뒤에는 홈으로 돌아옵니다. 가리기 토글은 저장 목록에만 남고, 우리 집에서는 가리기가 없어졌습니다. 저장 형식과 쓰기는 바뀌지 않았습니다.

**홈 계정 자리**

- 로그아웃: 로그인 안내 + [카카오로 로그인]("…다른 사람과 함께 쓸 수 있어요")
- 로그인: "카카오 계정에 저장 중 · [로그아웃]", 둘째 줄 [함께 쓰기] 또는 "2명이 함께 쓰는 중 · [나가기]"
- 안내 줄: 로그인 결과, 로그아웃 실패, 나가기 결과, 세션 만료, 매물 이전 실패 + [다시 시도], 계정 확인 실패 + [다시 시도]
- 로그아웃·나가기·시트가 열린 채 401일 때 포커스는 결과 안내 줄(없으면 계정 자리)로

**서버**: 카카오 로그인 302 `Location`이 `#/listings[?login=]` → `#/[?login=]`. 초대로 시작한 로그인 성공은 지금처럼 초대 화면. 엔드포인트·본문 변경 없음.

**저장 목록**: 머리에 [가리기][목록 공유]만. 세션 만료 안내에 [홈에서 로그인]. [가리기]에 보조기기 설명 "이 기기에서 저장 목록의 금액과 메모를 가립니다".

**우리 집**: [가리기] 버튼과 가림 삭제(가리기 관련 죽은 코드 삭제). 세션 만료 안내에 [홈에서 로그인].

**문구**: 초대 화면 "저장 목록에서 [나가기]" → 홈, 이전 손상 안내 "홈에서 로그아웃하면…", 함께 쓰기 시트·초대 결과·로그인 안내에 인테리어 계획.

## 팀이 내린 결정

- [ADR-035](../decisions/035-hub-account.md): D1 A(로그인 복귀 홈), D2 A(함께 쓰기 코드는 Hub로, `LinkCopyActions`·시트 본문 스타일은 전역 승격), D3 B(`MaskedValue` 전역 유지 — 홈 계산 카드 매매가는 계속 가림).
- 서버 테스트는 node 대신 workerd 프로젝트에서(`session.ts`가 workers 타입 사용, tsconfig를 늘리지 않음).
- 검토 권장: 없음(저장 형식 무변경).

## 화면 확인

**확인함**(dev, 360×780, 로그아웃)

- `#/?login=cancelled` → 홈 "로그인을 취소했습니다" 한 번, 주소 `#/`, 뒤로 돌아오면 안내 없음
- 저장 목록 머리에 로그인·함께 쓰기 없음
- `privacy-mode` 켬: 우리 집 머리글 [⋯]만·금액 보임, 홈 우리 집 줄 금액 보임

**못 함**(dev에 API 없음·배포 뒤)

- 로그인 상태 홈 계정 두 줄 배치(글자 크기 큼), 시트 inert·포커스 실제 위치
- 실제 카카오 로그인 성공·취소 → 홈(카카오톡 인앱 포함), 초대 링크 로그인 → 초대 화면
- 첫 로그인 착지 때 카드 밀림

## 사용자 확인 필요

- U3 저장 목록에 "함께 쓰는 중" 표시 없음(대안: 읽기 전용 표시 → 홈)
- U6 가리기를 켜도 홈은 계산 카드 매매가만 가리고 우리 집 금액은 보임(대안: 홈도 안 가림)

## 남은 이슈

- 로그인 착지가 홈이라 매물 "이전 완료" 알림은 저장 목록을 열 때 보입니다(실패는 홈에 보임).
- 초대 수락 화면은 "내 인테리어 계획도 숨겨진다"를 알리지 않습니다(알려진 갭).
- 저장 목록 카드의 가리기 연결을 보는 화면 테스트가 하나뿐입니다.

## 규칙 제안

- 사용자가 바로 진행하길 원하는 작업에 시간 대기 게이트를 두지 않습니다(이번에 24시간 게이트를 사용자가 뒤집음, 메모리 기록).
