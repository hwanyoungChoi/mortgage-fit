# 인테리어 [+] 색을 왼쪽 알약 탭과 같게

## 결과

인테리어 탭의 [+]가 왼쪽 알약 탭 바탕과 같은 흰 면(`--color-surface`), 먹색 아이콘(`--color-text`), 같은 그림자를 쓴다.

요청 원문: "인테리어 탭의 추가버튼 (+) 도 왼쪽 알약 탭이랑 색상 맞춰줘 동일하게"

## 바뀐 것

- `PlanLines.module.css` `.addFab`: 배경·아이콘·그림자를 알약(`.tabs`)과 같은 토큰으로. 줄 수 상한에서 꺼진 회색 상태는 그대로.
- `index.css`: 알약에 직접 적혀 있던 그림자 값을 토큰 `--shadow-floating`으로 옮김(`TabNav.module.css`가 사용, 보이는 결과 같음).

## 확인

- qa 360px·1280px: [+]와 알약의 배경·아이콘색·그림자·높이가 같음, 눌림·키보드 포커스·상한 꺼짐 정상. 다른 탭 알약 그림자는 main과 같음.
- lint·test(2939)·build 통과.
- 사람 확인 필요: 실기기 터치, iOS 하단 안전 영역 여백.

## 남은 이슈

- 상한에서 꺼진 [+]는 그림자가 없어 흰 줄 카드 위에서 윤곽이 약함(변경 전과 같음).
