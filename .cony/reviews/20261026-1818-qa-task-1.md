## 확인 필요 (결함 아님, 리드 판단)

1. **AC-0(g) 문구와 기존 session-hint 동작**: `src/hooks/useListingSource.ts:157-158`이 로그인 확인 결과마다 `session-hint`를 정리한다(user null → `removeItem`, 로그인 → `setItem("1")`). 이번 사이클 전부터의 동작이고 값이 "로그인 상태 캐시"라 맞는 동작이지만, 스펙 "기존 키 읽기 경로(… 로그인 확인 …)에서 setItem·removeItem·clear 0회"를 글자 그대로는 만족하지 못한다. 테스트는 응답 전 엄격 0회 + 로그아웃 뒤 `removeItem(session-hint)`만 허용으로 고정했다. 스펙에서 session-hint를 "로그인 확인이 갱신하는 키"로 예외로 적을지 리드가 정한다(담당 pm/리드, 코드 수정 불필요).
2. **가리기와 항목 시트**: `src/containers/Mortgage/Home/components/ItemSheet.tsx`는 가리기 값을 받지 않아, 가리기를 켠 채 항목을 열면 입력칸에 예산·견적 금액·연락처·메모가 보인다(AmountInput 힌트 "n만원"도). 플랜 화면(요약·할 일·묶음·줄)은 모두 가린다. 저장 목록도 편집(메모 편집기·계산 화면)은 가리지 않으므로 같은 규칙으로 보이나, 스펙 "가리기 켜면 금액·연락처·메모를 렌더하지 않음"이 시트까지 포함하는지는 리드 확인 필요(포함이면 fe).
