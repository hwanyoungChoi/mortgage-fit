## 변경 파일

- `src/index.css`: 알약 그림자를 토큰 `--shadow-floating`으로 올림(값은 TabNav에 있던 `0 0 8px rgb(0 0 0 / 8%), 0 4px 40px rgb(0 0 0 / 10%)` 그대로, 새 값 없음). `--shadow-lifted` 주석에서 "떠 있는 [+]"를 뺌(이제 끌고 있는 줄만 씀).
- `src/components/TabNav.module.css`: `.tabs` 그림자 → `var(--shadow-floating)`. 보이는 결과는 같음.
- `src/containers/Mortgage/Home/components/PlanLines.module.css`: `.addFab`
  - 배경 `--color-primary`(먹색) → `--color-surface`(흰 면, 알약 바탕과 같음)
  - 아이콘 `--color-on-primary`(흰색) → `--color-text`(먹색, 선택 탭 라벨과 같음)
  - 그림자 `--shadow-lifted` → `--shadow-floating`(알약과 같음)
  - 테두리: 알약과 같이 없음(기존 `border: 0` 그대로). 크기·위치·모양(원) 그대로.

## 맞춘 기준과 판단

- 알약 바탕(컨테이너 `.tabs`)에 맞춤: 흰 면 + 같은 그림자. "선택된 탭"(`--color-bg` 회색 알약)에 맞추지 않은 이유: 선택 표시는 "지금 이 화면"이라는 뜻이라 [+]가 선택된 탭처럼 보이면 안 되고, 사용자가 말한 "왼쪽 알약"은 바깥 면이다.
- 아이콘 색: 알약 안 글자색은 둘(선택 `--color-text`, 비선택 `--color-text-muted`). 누를 수 있는 동작이고 "조작은 먹색" 규칙(PR #65)이라 `--color-text`. 비선택 회색이면 꺼진 버튼처럼 보임.
- 대비(확인한 값, 상대 휘도로 계산): 아이콘 #191f28 대 흰 면 #fff ≈ 16.9:1 (기준 3:1 이상). 흰 면 대 바탕 #f3f5f7은 면 대비가 낮지만 알약과 같은 조건이고 그림자로 구분됨(알약과 동일).
- 눌림: 전역 `:where(button:active)` (scale 0.98 + brightness 0.95)를 그대로 따름. 알약의 탭은 `<a>`라 눌림 표시가 없어 "똑같이"가 될 수 없음 — 버튼 눌림 규칙(스펙 ui-refresh 규칙 5)을 유지. 흰 면에서는 약간 회색으로 어두워짐.
- hover: 알약도 [+]도 hover 규칙 없음 → 같음.
- focus: 전역 `:focus-visible`(2px 먹색 테두리, offset 2px). 알약 탭은 알약 안쪽이라 offset -2px로 덮어씀; [+]는 바깥 원이라 2px 바깥 테두리가 맞아 그대로 둠.
- 꺼진 상태(`:disabled`, 줄 수 상한 도달)는 그대로 둠: `--color-raised` 면 + `--color-text-muted` 아이콘 + 그림자 없음. 이유: 꺼진 버튼이 알약과 같은 흰 면·그림자면 켜진 것과 아이콘 색만 달라 구분이 약함. 위에 상한 안내 문구(limitNote)도 뜸. 리드/사용자가 꺼진 상태도 알약 면으로 원하면 한 줄 바꾸면 됨(결정 필요는 아님).
- 어두운 모드: 없음(`:root { color-scheme: light }`, `prefers-color-scheme` 규칙 없음) — 확인한 사실.

## qa 화면 확인 항목 (밝은 모드만, 360px 폭 + 넓은 폭 하나)

1. 인테리어 탭 진입(하단 탭 "인테리어"). 목록 보기에서 하단 알약 오른쪽 [+]가 알약과 같은 흰 면·같은 그림자, 먹색 + 아이콘인지. 알약과 높이·아랫선 같고 위치 그대로인지.
2. 360px: 알약과 [+] 사이 8px 간격 유지, 줄 겹침 없음. 본문 카드(흰 면)가 뒤로 지나갈 때 [+] 윤곽이 그림자로 보이는지(알약과 같은 정도인지).
3. [+] 누르는 동안 살짝 줄고 어두워지는지, 놓으면 줄 추가 시트가 열리는지.
4. 키보드 Tab으로 [+]에 포커스 → 먹색 2px 테두리가 원 바깥에 보이는지.
5. 줄 수 상한(INTERIOR_ITEM_MAX_COUNT)에 닿으면 [+]가 회색 면·회색 아이콘·그림자 없음으로 꺼지는지(기존 동작).
6. 다른 탭(홈·계산·매물) 알약 그림자가 전과 같은지(토큰으로 옮겼을 뿐 값 동일).
