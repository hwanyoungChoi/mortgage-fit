## 자동 테스트로 지킨 것 (태스크 2)

- AC-6 새 줄: 도배 접기 → 떠 있는 [+ 줄 추가]로 구분 "도배" 입력 → 계획 키 `setItem`만 throw시켜 저장 → 시트에 "저장하지 못했습니다", 도배 `aria-expanded=false`, 원문 `{"plan-simple":["도배"]}` 그대로 → throw 풀고 다시 저장 → 시트 닫힘, 도배 펼침, 새 줄(가나도배) 보임, 원문 `{}`.
- AC-6 고친 줄: 욕실 접기 → R1(도배) 시트에서 구분을 "욕실"로 바꿔 저장 → 욕실 펼침, 욕실 묶음 안에 "욕실 육문수 실크 전체 열기" 줄, 원문 `{}`.
- AC-5: 도배 줄 1개 계획, 원문 `{"plan-simple":["주방","욕실"]}`(주방 = 지금 화면에 없는 옛 이름) → R1을 "벽지"로 바꿔 저장 → 도배 묶음 없음, 벽지 펼침, 접힌 욕실 그대로 → 벽지 접기 → 원문 `{"plan-simple":["욕실","벽지"]}`(주방 정리됨).
- 조작 변경으로 고친 기존 것: 제목(손잡이) 클릭 뒤 `aria-expanded` 그대로, 화살표 클릭·엔터로 접고 펴기, 화살표에서 스페이스 = 접기이고 손잡이 `aria-pressed` 안 붙음, 손잡이 스페이스 들기→놓기 뒤 접힘 그대로(펼침·접힘), 접힌 욕실 들어 옮긴 뒤 화살표 순서·`aria-expanded`, 묶음 1개 계획은 제목이 버튼이 아니고(heading 이름 "도배 · 2줄") 화살표가 엔터·스페이스 둘 다로 접힘.

## 화면에서 확인할 항목 (qa)

진입: 로그아웃(또는 로그인) → [인테리어] → 묶음 2개 이상 계획 `#/home/{planId}` → [목록].

1. 360px: 묶음 제목 줄 오른쪽 끝에 화살표(펼침 ∧, 접힘 ∨), 확정 합계가 줄 금액 열과 같은 오른쪽 선, 화살표가 "완" 열 위에 오는지. 긴 구분(예 "주방 가구·상판·싱크대 전체 교체와 후드")은 제목이 여러 줄로 감기고 "· n줄"은 끊기지 않으며 화살표는 오른쪽 끝 자리에 그대로인지. 합계 없는 묶음에서 긴 이름이 화살표 밑으로 들어가지 않는지.
2. 화살표 탭/클릭 → 접힘(줄·[+ 구분에 줄 추가] 사라지고 제목 뒤 "· n줄") → 다시 → 펼침. 누를 자리가 48×44px 이상인지.
3. 제목 짧게 누르기: 아무 일 없음. 제목 꾹 누르기(250ms): 지금처럼 묶음 들기, 놓은 뒤 접힘 그대로.
4. 화살표 꾹 누르기·누른 채 끌기: 묶음이 들리지 않음(실기기 터치로 한 번).
5. 키보드: Tab 순서 제목(손잡이) → 화살표. 손잡이에서 스페이스 = 들기, 화살표에서 엔터·스페이스 = 접기. 묶음 1개 계획은 제목이 탭 정지 아님, 화살표만.
6. 자동 펼침: 묶음 하나 접고 떠 있는 [+]로 그 구분 줄 저장 → 펼쳐지고 새 줄 보임. 펼친 줄을 열어 구분을 접힌 묶음 이름으로 바꿔 저장 → 그 묶음 펼쳐짐. 저장 실패(로그인 상태 네트워크 끊기 등) → 시트 열린 채, 접힘 그대로.
7. 순서 저장 중(PATCH 지연): 제목에 끌기 속성 없음(글자), 화살표로 접기 됨.
8. VoiceOver: 화살표에서 "도배 접기/펼치기, 버튼, 펼침/접힘"으로 읽히는지.
