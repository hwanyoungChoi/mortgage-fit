## qa 화면 확인 항목 (AC-3·4·5, 390px)

느린 응답 재현 방법(확인한 것: `vite.config` 프록시 `/api` → `localhost:8788`, `pnpm dev` + `pnpm dev:api`):

- 권장: `pnpm dev` + `pnpm dev:api`로 띄우고, Chrome DevTools Network에서 요청 차단·지연을 건다. 사용자 정의 throttling 프로필(지연 1500ms / 100ms)을 쓰거나, "Slow 4G"를 쓴다. 특정 요청만 늦추려면 DevTools > Network > 해당 요청 우클릭 > "Override/Block"는 지연을 걸 수 없으므로 전체 throttling을 쓴다.
- 로그인 상태가 필요한 항목은 dev:api(wrangler)에서 카카오 로그인이 되는지에 따라 다르다(추론, 확인 안 함). 안 되면 로그아웃 상태로 홈의 `/api/me` 지연만 보고 "로그인 화면 확인 못 함"으로 적는다.

1. 홈(`#/`), 로그인·매물 1개 이상·계획 1개, 지연 1.5초: 홈 제목·카드 제목·대출 계산 카드 내용은 바로 보임. 약 300ms 뒤 매물·예산 카드의 두 줄 막대와 제목 줄 오른쪽 알약 막대가 은은하게 깜빡임. 응답이 다 오면 두 카드 숫자·[로그아웃]·함께 쓰기 줄이 **동시에** 나타남. 그 순간 세 카드와 계정 자리의 `top`이 바뀌지 않음(DevTools에서 `getBoundingClientRect().top` 전후 비교, 오차 1px).
2. 홈, 지연 100ms(또는 throttling 없음): 회색 막대가 한 번도 보이지 않고 바로 내용이 나옴.
3. 홈 → 매물 탭 → 홈: 돌아왔을 때 스켈레톤이 보이지 않음.
4. 매물(`#/listings`) 첫 진입, 지연 1.5초: 예산 줄·표 머리("이름 / 필요한 자기자금")·줄 3개 모양의 막대. "예산을 불러오는 중"·"직접 정한 순서를 불러오는 중"이 보이지 않음. 다 오면 예산 줄·목록·[가리기]·[목록 공유]가 함께 나타남. 첫 줄 `top` 전후 비교.
5. 예산(`#/home`), 계획 1개(연결 매물 없음), 지연 1.5초: h1 "예산" 아래 요약 카드·묶음 2개 모양의 막대. 다 오면 계획 화면(계획 이름 머리글)으로 바뀜. 요약 카드 `top` 전후 비교.
6. 계산 화면에서 실거래가 시트를 열어 조회 중: 44px 막대 3개, 같은 맥박·지연.
7. 다크 모드(DevTools Rendering > `prefers-color-scheme: dark`): 홈의 카드 위 막대(흰 면 위)와 제목 줄 알약(바탕 위)이 면과 구분됨.
8. 줄어든 움직임(DevTools Rendering > `prefers-reduced-motion: reduce`): 막대가 맥박 없이 멈춘 회색으로 300ms 뒤 나타남.
9. grep: `src/**/*.css`에 `gradient` 0건, `Skeleton.module.css`에 `#`·`rgb(` 0건(실행해 확인함, 0건).
