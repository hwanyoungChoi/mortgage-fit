# 전체 UI 개편: "표준 AI 티" → 소비자 금융 앱 스타일

## 요청(원문)

- "우리집인테리어 페이지 타이틀 아래에 버튼이있어서 공간낭비임. 다른페이지처럼 타이틀과 같은라인 우측에 놔"
- "전체적으로 ui 바보 표준 스탠다드 ai티가 난다. 요즘 플랫폼 트랜디한 스타일로 개편해라"

## 진단(지금 화면, 390px)

- 지금 팔레트가 "장부(achromatic ledger)"다: 크롬에 색이 없고 주 동작이 거의 검정, 1px 회색 테두리 상자, 8px 각진 카드, 2px 검정 테두리로 선택 표시. 정리돼 있지만 템플릿처럼 보인다.
- 입력칸·선택 버튼이 전부 흰 바탕 + 회색 1px 테두리라 화면이 "양식"처럼 읽힌다.
- 돈(답)이 크지 않다. 계산 화면 요약 줄의 답은 16px대, 우리 집 요약은 20px대.
- 화면마다 머리글 구조가 다르다(우리 집은 [⋯]이 제목 아래 줄을 차지).

## 방향(design-taste-frontend `--app`, kind finance, style **pastel-consumer**, seed 761047964)

한국 소비자 금융 앱(토스·뱅크샐러드 계열)의 관례: 회색 바탕 위 흰 카드에 큰 라운드, 테두리 대신 면 한 단계, 채운 입력칸, 파란 주 동작, 큰 돈 숫자.

**이 제품의 얼굴**: 돈 숫자가 얼굴이다. 답이 되는 금액(예상 한도·필요한 자기자금, 남은 예산·지출 예정, 매물의 자기자금)을 Pretendard 28~32px 700, tabular, 화면에서 가장 크게. 주 데이터 한 가지에만 코발트(남은 예산, 예상 한도).

### 컴포넌트 규칙

1. **머리글(모든 화면 같은 구조)**: 제목 왼쪽, 동작 버튼 오른쪽, **같은 줄**(줄바꿈은 360px에서 넘칠 때만). 제목 아래 보조 줄(기준일 등)은 13~14px muted. 우리 집 계획 화면은 계획 이름 줄 오른쪽에 [⋯]. 저장 목록·계산 화면도 같은 자리.
2. **카드**: 흰 면, 반경 20px, 테두리·그림자 없음(바탕과 면 한 단계로 구분), 안쪽 여백 20px, 카드 사이 12px.
3. **입력칸**: 채운 칸(`--color-raised`), 테두리 없음, 반경 12px, 높이 52px, 라벨은 위 14px 600. 포커스는 2px 코발트 링. 오류는 2px 오류색 링 + 아래 문구. 단위("원"·"만원")는 칸 안 오른쪽 muted.
4. **선택 버튼(세그먼트·칩)**: 선택 안 됨 = `--color-raised` 채움, 테두리 없음, 잉크 글자 500 / 선택됨 = `--color-accent-soft` 채움 + `--color-accent-ink` 글자 600. 2px 검정 테두리 없앰.
5. **버튼**: 주 동작 = 코발트 채움, 흰 글자 600, 반경 14px, 화면 하단 고정이면 52px. 보조 = `--color-raised` 채움 잉크 글자. 텍스트 동작 = 코발트 글자. 위험 동작 = 오류색 글자 + 옅은 오류 바탕. 눌림(`:active`) 시 scale(0.98)·한 단계 어두운 채움, 120ms.
6. **확정 체크(우리 집 줄)**: 24px 원형, 꺼짐 = 회색 테두리 원, 켜짐 = 코발트 채움 + 흰 체크. 누르는 영역 44px 이상 유지.
7. **줄 목록**: 묶음(구분)마다 흰 카드 하나, 묶음 제목은 카드 안 첫 줄 15px 600, 줄 사이 구분선 없음(56px 간격) 또는 `--color-rule` 1px. 금액은 오른쪽 정렬 tabular 16px 600, "미정"은 muted.
8. **요약(답)**: 우리 집 요약 카드 — 남은 예산(코발트, `--fs-answer`)과 지출 예정(잉크, `--fs-answer`)이 가장 큰 글자. 예산 초과는 오류색. 계산 화면 하단 요약 줄 — 예상 한도·필요한 자기자금 20px 700, [저장] 코발트.
9. **하단 탭**: 흰 면, 위 1px `--color-rule`, 활성 = 잉크 아이콘 + 라벨 600, 비활성 = muted. 활성 회색 알약 배경 없앰.
10. **시트**: 위쪽 반경 24px, 손잡이(36×4 회색 막대) 하나, 머리글 제목 18px 600 + 오른쪽 [닫기] 텍스트 버튼.
11. **홈 허브**: 계정 자리 카드, 기능 카드 3개는 큰 흰 카드(대출 계산 카드가 가장 큼), 카드 제목 20px 700, 소개 15px muted, 내 현황 줄은 숫자 강조(잉크 600). 카카오 로그인 버튼은 카카오 노랑 유지(브랜드 규정).
12. **배지·알림 줄**: 옅은 같은 색 바탕 + 진한 같은 색 글자, 반경 12px, 테두리 없음.
13. **떠 있는 [+]**: 코발트 56px 원, 그림자는 떠 있는 것이라 허용(약하게).

### 금지(이번 개편에서도)

## 수용 기준

- AC-1 우리 집 계획 화면에서 [⋯]이 계획 이름과 같은 줄 오른쪽에 있다(390·360px). 다른 화면 머리글도 같은 구조.
- AC-2 위 토큰·컴포넌트 규칙이 홈·계산·저장 목록·우리 집·초대·공유 화면과 시트 전부에 적용된다. 흰 바탕 + 1px 회색 테두리 입력칸·선택 버튼, 2px 검정 선택 테두리가 남지 않는다(grep).
- AC-3 대비: 글자가 있는 모든 색 조합 4.5:1 이상(muted, 탭 비활성, 선택 칩 글자, 코발트 버튼의 흰 글자).
- AC-4 동작 무변경: 기존 테스트 전부 통과, 테스트 수정은 마크업 구조가 바뀐 곳의 선택자뿐(단언 약화 0).
- AC-5 360px에서 가로 스크롤 없음, 글자 크기 설정 3단계에서 머리글·하단 요약이 깨지지 않음.
