# ADR-037 카카오 닉네임을 받아 브라우저 쿠키에만 둔다

- 상태: 채택(사용자 요청: "카카오 로그인한 계정 이름도 노출해줄 수 있나 로그인 옆에")
- 맥락: ADR-023은 회원번호만 받고 닉네임을 저장하지 않기로 했다. 화면에 이름을 보이려면 카카오에서 받아 어딘가 두어야 한다.
- 선택지: A `users` 컬럼(D1) / B HttpOnly 쿠키 / C 토큰을 저장해 매번 조회
- 결정: B. `mf_nickname`(HttpOnly, Path=/api, 1년). 세션이 살아 있을 때만 `/api/me`가 돌려주고 로그아웃·동의 철회 뒤 로그인이면 지운다. 동의항목은 사용자가 필수 동의로 설정했다(2026-11-02). 동의하지 않으면 로그인이 취소된다. 나중에 선택 동의로 바꿔도 동작하도록 닉네임이 없는 응답도 그대로 처리한다.
- 이유: 요구는 "이 화면에 내 이름 표시"뿐이다. B는 DB 변경과 운영 마이그레이션이 없고 ADR-023의 "서버에 닉네임을 저장하지 않는다"를 지킨다. 새 Worker + 옛 스키마 골든도 그대로 통과한다. A는 처음에 구현했으나 마이그레이션 전 배포에서 `/api/me`가 500이 되는 것을 골든이 잡았다. C는 저장하지 않기로 한 토큰을 저장해야 한다.
- 배포 순서: 카카오 콘솔에 닉네임 동의항목을 설정한 뒤 머지한다. 설정 없이 scope를 보내면 카카오가 인가를 거절할 수 있어 로그인 전체가 막힐 수 있다.
- 알려진 한계: 기존 사용자가 다음 로그인 때 동의를 거절하면 로그인이 안 되어 서버에 저장한 목록·계획을 볼 수 없다(리드는 선택 동의를 권했고 사용자는 필수를 골랐다). 이미 로그인한 세션은 다시 로그인하기 전까지 이름이 보이지 않는다. 카카오 닉네임을 바꿔도 그 기기는 다음 로그인까지 옛 이름이다.
- 뒤집을 조건: 다른 사람의 이름을 보여 줘야 하면(함께 쓰는 사람 표시 등) A로 옮긴다.
