# ADR-038 예산 외 항목: 항목 필드 `isOffBudget?: true`, 1단계 배포

- 상태: 채택
- 맥락: 함께 쓰는 사람이 "구매 완료한 것 중 예산 밖에서 산 것도 있으니 예산 반영/미반영을 고르게 해 달라"고 요청했다. 저장 위치(항목·견적·enum)와 배포 단계를 정해야 한다.
- 선택지: A 항목 `isOffBudget?: true`(false는 받아서 키 없음으로 저장) / B 견적 단위 플래그 / C 항목 enum(budget·off·…)
- 의견: fe(찬성 — 계산이 `buildInteriorPlanRows`·`groupConfirmedWonOf` 두 곳에 모여 있고 draft 비교로 저장 활성이 공짜) / be(찬성 — 서버가 클라이언트 검증 함수를 그대로 써서 키만 더하면 서버 diff 0, 옛 번들은 모르는 키를 버릴 뿐 손상 판정 안 함 → 1단계 배포로 충분. B는 확정 견적 이동 시 값이 안 따라옴) / qa(찬성 — 예시 E 계산 검증, 경계 true/false/없음/null/"true"/1 판정 가능)
- 검토 원문: [fe](../reviews/20261106-1025-fe-spec-interior-budget-exclude.md) · [be](../reviews/20261106-1025-be-spec-interior-budget-exclude.md) · [qa](../reviews/20261106-1025-qa-spec-interior-budget-exclude.md)
- 결정: A, 1단계 배포(게이트 없음, 배포 보고에 "두 분 탭 새로고침" 한 줄)
- 이유: 가장 단순하고(키 하나, 없으면 반영), 기존 ADR-012의 "false는 키 없음" 규칙과 같다. 저장 형식 완화가 아니라 선택 키 추가라 옛 번들이 손상으로 읽지 않는다(ADR-029 조건 2). 두 사람뿐이라 단계 배포를 넣지 않는다.
- 조건(스펙 반영): 검증은 `parseOptional` 대신 전용 판정(true→키, false/없음→키 없음, 그 외→null), `false`가 반환 객체에 새지 않게. 미확정 줄에도 "예산 외" 표시 여부 명시. 예산 외 줄만 완료일 때 요약·홈·표 "계" 완료 칸 일치. 총 예산 없을 때 "예산 외 n원" 표시 AC. 미정+확정+예산 외 fixture와 계 비고 순서. AC-2 입력에 0·"false"·[]·{} 추가. 남는 위험에 "오래된 캐시의 PUT이 키를 지워 반영으로 되돌릴 수 있음(손실 아님)".
- 뒤집을 조건: 견적마다 일부만 예산 외인 경우가 실제로 생기면 B를 다시 본다.
- 제품 기본값(U1~U7)은 이 결정에 포함되지 않는다 · 사용자 확인 전.
